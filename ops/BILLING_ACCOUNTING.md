## 4. Домены и маршрутизация

Все внешние запросы терминируются на американском Edge-шлюзе `evaline-micro-vm` (`136.114.26.252`, Caddy 2.11) и перенаправляются по шифрованной WireGuard Mesh-магистрали во Франкфурт на `evabot-agent-vm`:

* **`evabot.online` / `www.evabot.online`**: Основной TUI-интерфейс и REST API.
* **`evaline.network` / `www.evaline.network`**: Интерактивная топология Tetraktys и ростер агентов.
* **`evaline.online` / `www.evaline.online`**: Трехъязычный манифест и бизнес-портал.
* **`evaline.website` / `www.evaline.website`**: Главный хаб экосистемы и навигационный портал.
* **`evaline.com.ua`**: Региональный шлюз.
* **`business.evaline.online`**: B2B Cloud Run микросервис со Stripe metering.
* **`billing.evabot.online` / `billing.evaline.online` / `billing.evaline.network`**: Выделенный субдомен бухгалтерии.
* **`/billing/` (через слэш)**: Доступен на всех доменах с прямым алиасом на `/var/www/billing/`.

## 6. Как собирать реальные метрики и строить автоматическую бухгалтерию

Для автоматизации финансового учета настроен 5-компонентный конвейер:

```
┌────────────────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│ GCP Cloud Billing      │      │ LiteLLM / OmniRoute     │      │ OpenRouter & Stripe     │
│ BigQuery Export        │      │ /spend/calculate (20128)│      │ Key Balance API         │
└───────────┬────────────┘      └───────────┬─────────────┘      └───────────┬─────────────┘
            │                               │                                │
            └───────────────────────┬───────┴────────────────────────────────┘
                                    ▼
                     ┌──────────────────────────────┐
                     │ EvaBot AccountingEngine.ts   │
                     │ (SQLite Ledger & In-Memory)  │
                     └──────────────┬───────────────┘
                                    ▼
       ┌────────────────────────────┴───────────────────────────┐
       ▼                                                        ▼
┌──────────────────────────────┐              ┌──────────────────────────────────┐
│ Web Dashboard                │              │ CLI & API Interfaces             │
│ https://evabot.online/billing│              │ /cost command  &  /api/billing   │
└──────────────────────────────┘              └──────────────────────────────────┘
```

1. **GCP Cloud Billing Export в BigQuery:**
   * Включен ежедневный экспорт детального биллинга GCP в BigQuery (`billing_export.gcp_billing_export_v1_*`).
   * Позволяет агрегировать точные затраты до цента по каждому SKU (Compute Engine, Hyperdisk, Cloud Egress, Cloud Storage).
2. **LiteLLM Spend Logs:**
   * OmniRoute прокси (порт 20128) логирует точное количество токенов каждого запроса и стоимость в SQLite базу `/opt/omniroute/spend.db`.
3. **OpenRouter API Key Balance:**
   * Автоматический запрос к `https://openrouter.ai/api/v1/auth/key` каждые 6 часов для сверки остатка предоплаченного буфера.
4. **AccountingEngine Core:**
   * Класс `src/core/AccountingEngine.ts` агрегирует метрики, рассчитывает юнит-экономику агентов и отдает данные по API `/api/billing`.
5. **Алертинг при превышении лимита:**
   * Система отправляет предупреждение уровня HIGH в `AlertManager` и Telegram-канал при превышении суточного расхода свыше $10.00.
